  DEPLOY DANAI TASK MANAGER TO RENDER - STEP BY STEP
═══════════════════════════════════════════════════════════════

📋 STEP 1: CREATE GITHUB REPOSITORY
─────────────────────────────────────────────────────────────────

1. Open: https://github.com/new

2. Repository name: danai-task-manager

3. Description: AI-powered smart task manager

4. Make it PUBLIC (required for free Render)

5. DO NOT check any boxes

6. Click "Create repository"

7. Copy the commands shown (something like):
   git remote add origin https://github.com/YOUR-USERNAME/danai-task-manager.git
   git branch -M main
   git push -u origin main

8. Come back here after creating the repo!


📋 STEP 2: PUSH CODE TO GITHUB
─────────────────────────────────────────────────────────────────

Once you've created the repo on GitHub, tell me and I'll help you push!

Or if you already created it, run:
  
  git remote add origin https://github.com/YOUR-USERNAME/danai-task-manager.git
  git branch -M main  
  git push -u origin main


📋 STEP 3: DEPLOY ON RENDER
─────────────────────────────────────────────────────────────────

1. Go to: https://render.com

2. Sign up with GitHub (FREE!)

3. Click "New" → "Web Service"

4. Click "Connect GitHub" and select your repo

5. Settings:
   ✅ Name: danai-task-manager
   ✅ Region: Oregon (Free Tier)
   ✅ Branch: main
   ✅ Runtime: Node
   ✅ Build Command: npm install && npm run build
   ✅ Start Command: npm start
   ✅ Auto-Deploy: Yes

6. Click "Add Environment Variable" → Add these:
   🔸 NODE_ENV = production
   🔸 DATABASE_URL = (leave for now, we'll add after DB creation)
   🔸 OPENROUTER_API_KEY = YOUR_API_KEY_FROM_.ENV

7. Click "Create PostgreSQL" (in same dashboard):
   ✅ Name: danai-db
   ✅ Plan: Free
   ✅ Click "Create Database"
   ✅ Copy the "Internal Database URL"
   ✅ Go back to Web Service → Environment
   ✅ Update DATABASE_URL with the Internal URL from PostgreSQL

8. Click "Create Web Service"

9. Wait for deployment (3-5 minutes)

10. **COPY YOUR APP URL**: It will be something like:
    https://danai-task-manager-XXXX.onrender.com


📋 STEP 4: UPDATE APK
─────────────────────────────────────────────────────────────────

Once deployed, your app URL will be on Render dashboard.

Tell me the URL and I'll update the APK to connect to it!
