## Troubleshooting

### Installation Issues

**"App not installed" error:**
- Make sure you've enabled "Install from Unknown Sources"
- Try downloading again - the file might be corrupted
- Check if you have enough storage space

**App crashes on launch:**
- Make sure you have internet connection
- Try clearing app data and reinstalling
- Check if your Android version is compatible (7.0+)

**Notifications not working:**
- Go to Settings → Apps → Daniyal To-Do → Notifications
- Enable all notification permissions
- Restart the app

### Server Connection Issues

If the app can't connect to the server:
- Check your internet connection
- The server might be sleeping (free tier limitation)
- Wait a few seconds and try again
- The app will retry automatically
